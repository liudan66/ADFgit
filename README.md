# ADFgit

This repository contains Azure Data Factory (ADF) configurations and a complete **Online Shopping Website** implementation.

## Projects in this Repository

### 1. Azure Data Factory (ADF)
Original ADF configurations and pipelines for data integration workflows.

### 2. Online Shopping Website (NEW)
A full-stack e-commerce application with React frontend and Node.js/Express backend.

**Quick Links:**
- [📖 Complete Setup Guide](./SHOPPING_README.md)
- [🚀 Quick Start Guide](./QUICKSTART.md) - Get running in 5 minutes!
- [🔒 Security Summary](./SECURITY_SUMMARY.md)

**Features:**
- User authentication & authorization
- Product browsing with search & filters
- Shopping cart management
- Order processing & history
- Admin product management
- Responsive design
- Secure & production-ready

**Tech Stack:**
- **Frontend**: React, React Router, Axios, Vite
- **Backend**: Node.js, Express, MongoDB, JWT
- **Security**: Rate limiting, input validation, NoSQL injection prevention

**Getting Started:**
```bash
# Backend
cd backend
npm install
npm run seed    # Add sample data
npm run dev     # Start server

# Frontend
cd frontend
npm install
npm run dev     # Start app
```

Visit http://localhost:3000 to see the application!

**Sample Accounts:**
- Admin: `admin@shopmart.com` / `admin123`
- User: `user@test.com` / `test123`

For detailed instructions, see [QUICKSTART.md](./QUICKSTART.md)
